# Detailed Feature Breakdown

## Objective

Break a main feature into smaller functional features.

This phase focuses on **behavior**, **responsibilities**, and **feature decomposition**.

Do NOT think about classes.

---

## Input

Approved Feature Mindmap.

---

## Output

Break the selected feature into:

- Responsibilities
- Sub-features
- Use cases
- Inputs
- Outputs
- Error cases
- External dependencies

Example

Create File

├── Validate Request

├── Generate File Id

├── Allocate Storage

├── Initialize Header

└── Register Metadata

---

## Rules

Focus on WHAT the feature does.

Do not think about HOW it is implemented.

Do not introduce:

- Classes
- Interfaces
- Design Patterns
- Methods
- Properties

---

## End

Stop after the breakdown.

Wait for review.
