# Test Documentation

## Objective

Write test specifications.

Do NOT write code.

---

## Input

Approved Complete Class Diagram.

---

## Unit Test

For every public behavior define

- Input
- Preconditions
- Execution
- Expected Output
- Expected State
- Dependency Calls

---

## Integration Test

Define

- Environment
- Scenario
- Expected Result
- Cleanup

---

## Rules

Test behavior.

Never test implementation details.
